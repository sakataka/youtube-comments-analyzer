# ローカル判定とX検索

2026-09-24。トークン消費を増やさずに全件の賛否・感情・人物別の評価を見ること、YouTube以外の反応としてXを参照することが目的。

## 実行の流れ

通常の分析（取得・要約・人物辞書）が終わると、同じ実行の続きとして次の2つを自動で実行する。停止した場合と取得件数が0の場合は実行しない。どちらかが失敗しても、要約・集計・原文はそのまま使える。

1. ローカル判定（`local`）：このMacで分類モデルを動かし、全件を判定する。AIのトークンは使わない。
2. X検索（`x`）：ローカルのGrok CLIでXを1回検索する。1つの分析で自動実行するのは1回だけで、失敗したときや再検索は画面のボタンから行う。24時間以内に同じ動画を再分析した場合は、前回の結果を引き継ぐ。

人物辞書を手で編集すると、ローカル判定だけを自動で再実行する。判定結果は文ごとにキャッシュしているため、2回目以降は変わった文だけを推論する。

## ローカル判定

- 賛否：`neuralnaut/deberta-wrime-sentiment`（WRIMEの書き手の極性を回帰し、-2〜+2で出力）。+0.15以上を肯定、-0.15以下を否定、その間を中立とする。極性が±0.3未満の疑問文（ゲストの予想など）は中立とする。
- 感情：`patrickramos/bert-base-japanese-v2-wrime-fine-tune`（WRIMEの書き手の8感情の強さ、0〜3）。最も強い感情が1.0以上ならその感情とし、それ未満は「目立つ感情なし」とする。
- 人物別：人物辞書に一致した投稿について、その人物の名前を含む文だけを賛否モデルで判定する。文ごとの判定に肯定と否定が混ざれば「両方」とし、平均して中立にはしない。以前のルール判定は折りたたんで残している。
- 上位と全体の比較に、賛否の割合（取得全件・いいね上位20件・いいねで重み付け）を追加した。
- 判定値は参考値。WRIME由来のデータはCC BY-NC-ND 4.0のため、個人利用に限る。

### モデル選定（2026-09-24、保存済み573件の動画）

- 以前（2026-07）に採用した `LoneWolfgang/bert-for-japanese-twitter-sentiment` は、「なんで本編より長いんだよ（歓喜）」「理不尽なおもろさがある」のようなお笑いのツッコミ調の褒め言葉を、確信度約0.82で否定と判定した。このため、いいね上位20件の35%が否定になり、実態と合わなかった。
- `neuralnaut/deberta-wrime-sentiment` では、上位20件のうち肯定90%・否定5%、全件で肯定63%・中立24%・否定13%となった（疑問文ルールを足した後は、上位20件で肯定85%・否定5%、全件で肯定58%・中立32%・否定10%）。ルールを足す前の否定74件を目視すると、大半は料金・配信方法への不満、出演者への苦言など実際の否定だった。「支離滅裂だからいい」のような逆説的な褒め言葉や、「関係性も沼」のようなスラングは誤判定が残る。
- 感情は、neuralnaut版の8感情よりpatrickramos版の方が強弱の差がはっきりしていたため、patrickramos版を採用した。
- M4 Proで、初回はモデルの読み込みを含めて約10〜20秒。人物ごとの文を含む742件の推論は数秒で終わる。

人手の正解ラベルによる精度評価は行っていない。

## X検索

`grok -p` をヘッドレスで実行する。ツールは `x_search` と `web_search`、JSON Schemaで出力を指定する。keyword-atlasのX Pulseと同じ方式で、プロンプトには動画タイトル・チャンネル・公開日時・人物辞書の上位8人・要約の話題名を渡す。

- 出力は、全体像、反応の温度感、話題ごとの投稿（最大3件）、YouTubeコメントとの違い。
- 投稿URLが `x.com/…/status/…` の形でない投稿は捨て、投稿が残らない話題も捨てる。
- 上限は8分（`X_SEARCH_TIMEOUT_SECONDS`）。途中で停止できる。事前に `grok login` が必要。
- 保存済みの動画で試したときは約4分で完了し、4つの話題と、公式アカウントを含む投稿URLが取れた。

## 設定

| 変数 | 既定 | 内容 |
| --- | --- | --- |
| `LOCAL_MODELS` | 有効 | `off` でローカル判定を止める |
| `X_SEARCH` | 有効 | `off` でX検索を止める |
| `GROK_BIN` | PATH上の `grok`、なければ `~/.grok/bin/grok` | Grok CLIの場所 |
| `GROK_MODEL` | Grok CLIの既定 | Grokのモデル |
| `X_SEARCH_TIMEOUT_SECONDS` | 480 | X検索の上限時間（秒） |

E2Eでは両方を無効にし、実モデルと実Grokを呼ばない。
