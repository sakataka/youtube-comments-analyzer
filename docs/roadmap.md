# 軽量分析への移行

2026-09-07に[次期設計](lightweight-analysis-design.md)を決定。設計のみ更新済みで、以下は未実装。

1. 全件の機械集計と原文閲覧をAIから独立させる。取得済みの今回の2,269件を最初の確認対象にする。
2. 再現可能なサンプル選定、入力・出力上限、Astra Lightによる要約を実装する。字幕全文整理、全件の意味付け、呼び名統一・意見統合・AI監査の多段処理を新規分析から外す。
3. 最終回答の受信、構造・引用検証、全体期限、停止、最大1回の修復を実装する。AI失敗でも集計と原文は使える状態を維持する。
4. report.v4と画面を実装し、取得範囲・AI抽出範囲・終了理由を表示する。抽出意見から全体の賛否率を出す表示を廃止する。
5. 既存runを保持したまま新方式へ切り替える。既存の原文を再利用し、v3のAI結果をv4の結果として混在させない。
6. 自動テスト・実ブラウザ確認後、今回の保存データで実AIの時間・呼び出し数・根拠を確認する。複数ジャンルでも欠落や偏りを確認し、実測に基づき上限を調整する。

以前の全件分類向けの品質基準と少量検証記録は[品質評価手順](quality-evaluation.md)に残す。次期方式の合否には次期設計の検証条件を使う。少量のテスト成功を5,000件での性能や分析精度の保証にしない。

映像解析・音声認識、外部情報による真偽検証、公開サービス化は引き続き対象外。
