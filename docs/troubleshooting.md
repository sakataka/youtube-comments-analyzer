# 動作確認と復旧

`GET /api/health`が`report_schema: report.v4`、`GET /api/settings`が`gpt-6-astra` / `low`を返すことを確認します。画面とAPIが食い違う場合はビルド後にこのアプリのAPIサービスだけを再起動します。

- **キー未設定**：`.env`の`YOUTUBE_API_KEY`を設定し再起動します。実URLをfixtureで代用しません。
- **AI失敗・利用制限**：集計・原文は引き続き利用できます。ログインと利用状態を確認し、必要なら「保存データから要約を再試行」を押します。試行回数と時間は履歴に残ります。
- **時間切れ**：取得は最大120秒、AIは1回最大180秒、全体600秒の期限があります。成功した要約を保証する制限ではありません。原文を読み、必要なら明示的に再試行します。
- **停止**：「停止して保存」でAI応答待ちを中断します。API取得中は現在のネットワーク要求のtimeoutまでかかる場合があります。再起動後の自動再試行はしません。
- **旧方式の結果**：旧runは保持されています。「新しい分析としてやり直す」で保存原文から新方式を実行します。旧結果は上書きしません。
- **部分取得**：続行で次の区切りを取得できます。抽出していないコメントはエラーではなく、原文検索で読めます。
- **E2Eがbind不可**：sandboxのloopback制約を確認します。E2Eは通常のDBとは独立した一時ディレクトリを使います。
