### 日本語解析

- 固有表現抽出モデルを検討する。
- 助詞・係り受けを使った alias 文脈判定を検討する。
- SudachiPy で未知のひらがなニックネームが細かく分割されるケースを継続観察し、人物名・愛称候補は「品詞だけで除外しない」補助ルールを育てる。
- 人物名・愛称候補と評価語を分けて抽出する。人物候補は固有名詞・人名・敬称・共起を重視し、特徴語やクラスタ keyword は名詞・形容詞・評価表現を重視する。
- `好き`、`良い`、`面白い`、`苦手` などの評価語を、対象人物へ正しく紐づけるための文脈判定を実装する。
- stopword 追加だけで対応した語を定期的に見直し、品詞・文脈ルールに置き換えられるものは共通化する。

## 運用・設定・データ管理

### データ管理

- 古い run と cache を削除または退避できるようにする。

### ジョブ実行

- 同時実行ジョブ数 1 の queued 状態を実装する。
- 実行中に新しい job が来た場合の待機表示を実装する。
- サーバー再起動後に `running` のまま残った job を `failed_recoverable` にする。
- 本格的な worker / queue 分離を検討する。

## API / データモデルの残り
